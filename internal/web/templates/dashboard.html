Your familiar Git workflow

Load the key registered in this workspace into your local SSH agent, then enable agent forwarding when connecting.

ssh -A -p 2222 git@your-proxy-host

This opens the management terminal. For Git, use your route’s exact source path:

git -c core.sshCommand='ssh -A' clone ssh://git@your-proxy-host:2222/team/project.git

Port 2222 is the default; use your configured SSH port. The SSH username is ignored: your registered key identifies you. The proxy forwards your agent to authenticate upstream.
