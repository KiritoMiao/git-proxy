Connect with your SSH agent

Configure agent forwarding once, then use your usual Git commands.

Enable ForwardAgent

Add this entry to ~/.ssh/config. Replace the host, port, and identity file with your proxy settings.

Host git-proxy
    HostName your-proxy-host
    Port 2222
    User git
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes
    ForwardAgent yes

ForwardAgent yes enables forwarding for this host alias, so you do not need ssh -A in each Git command. Use git-proxy in the commands below to match this entry.

Load your upstream key

ssh-add ~/.ssh/id_ed25519

The public key selected by IdentityFile must be registered in this workspace. Your agent must hold a key accepted by the upstream Git server; this may be a different key.

Clone your mapped repository

git clone git-proxy:team/project.git

Replace team/project.git with your route’s source path. The .git suffix is optional; the proxy adds it when omitted. When creating a route, a blank upstream host defaults to github.com. Fetch, pull, and push use the same SSH configuration.

Open the management terminal

ssh -t git-proxy

The management terminal does not require agent forwarding.

Why Git needs agent forwarding

Your registered key authenticates the connection to this proxy. The proxy then opens a separate SSH connection to the upstream Git server. Agent forwarding lets your local agent sign that second authentication request without transferring your private key.

Use forwarding for one command

If you prefer not to edit your SSH configuration, enable forwarding for a single clone:

git -c core.sshCommand='ssh -A' clone ssh://git@your-proxy-host:2222/team/project.git

For an existing checkout, use git -c core.sshCommand='ssh -A' fetch or enable ForwardAgent yes for the host used by its remote URL.

Check your setup

ssh-add -l
ssh -G git-proxy

ssh-add -l lists loaded agent keys. In ssh -G git-proxy, check hostname, port, and forwardagent yes.

Enable forwarding only for a proxy you trust. The proxy can request signatures from your agent while connected. Keep ForwardAgent yes scoped to this host rather than a wildcard.
